字体組立

KAGEデータ形式とkage-engine（GPLv3／@kurgm版）を用いて部品を合成する道具です。GlyphWikiから部品を検索して取り込み、組み立て台に実際の字形をそのまま描画します。

エンジン読み込み中…

1部品を探す

部首・部品から探す

2組み立て台

組み立て台の字を、そのままの形で交利(漢文エディタ)のカーソル位置に入れます。
選択部品x1y1x2y2回転°⇋⇵

検索結果の部品を押すと組み立て台に置けます。矩形はドラッグで移動、右下の■でサイズ変更（座標系は0〜200。灰色の部分まで、枠の外にはみ出して置けます）。灰色の枠線は余白ガイドです。漢文エディタに入れたとき、この枠がちょうど1文字分の大きさになります。四角は選んでいる部品にだけ表示されます。ほかの部品は、その部品の上を押すか、下の表のラジオボタンで選べます。選択中パーツの上に出る赤い丸のハンドルをドラッグすると好きな角度に回転できます（テーブルの「回転°」欄で数値入力も可）。表内の⇋⇵で左右反転・上下反転。「消しゴムモード」をONにすると投げなわ（クリックしたまま囲んで離す）でその範囲を消せます。選択中にBackspace/Deleteキーでそのパーツを削除できます。ショートカット：Ctrl+C コピー／Ctrl+V 貼り付け／Ctrl+Z 元に戻す／Ctrl+Shift+Z（またはCtrl+Y）やり直し。

クレジット
字形の描画:kage-engine(上地宏一・kurgm、GNU GPL-3.0)を、そのまま読み込んで使っています。
部品の検索・取り込み:kage-editor(kurgm、GNU GPL-3.0-only)と同じ方法で、GlyphWiki の API と kage-editor の作者が公開している中継サーバーを使っています。
部品の字形データ:GlyphWiki(利用条件は GlyphWiki:License に従います)。
